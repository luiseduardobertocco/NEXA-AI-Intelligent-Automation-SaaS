# NEXA AI

NEXA AI is a fictional SaaS landing page project designed for a frontend portfolio. It presents a premium AI automation product in a polished marketing website format.

## Project Overview

This project creates a modern SaaS-style landing page for a fictional AI workflow automation platform called NEXA AI. It is intended as a portfolio piece and demonstration website, showcasing responsive design, premium UI, Bootstrap integration, custom JavaScript interactions, accessibility best practices, and GitHub Pages-friendly static structure.

## Features

- Premium SaaS landing page design
- Responsive navigation and mobile menu
- Interactive hero with custom dashboard mockup
- Social proof, product storytelling, and value proposition sections
- Workflow showcase, features, integration cards, use cases, testimonials, and pricing
- Bootstrap accordion FAQ
- Modal-based sign-up demo
- Pricing toggle with monthly/yearly billing states
- Interactive workflow demo simulation
- Reveal-on-scroll animations with reduced motion fallback
- SEO-ready metadata and semantic structure

## Installation

1. Clone the repository.
2. Open the project folder.
3. Start a local static web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Deployment

This project is compatible with GitHub Pages:

1. Push the project to the `main` branch.
2. In GitHub, open the repository settings.
3. Navigate to Pages.
4. Select the root folder or `main` branch deployment.
5. Save and wait for the site to publish.
